# Mavuno product screenshots

Capture these screens from the running application using real farm data. Do not create substitute records or edit values into screenshots. Remove or obscure farmer names, contact details, and other personal information before committing images.

Recommended capture order and filenames:

1. `dashboard.png` — farm name, persisted livestock/alert/task counts, and Sentinel summary.
2. `animal-profile.png` — animal identity, photo or species fallback, and latest persisted assessment.
3. `observation-form.png` — the observation fields and selected symptoms before save.
4. `sentinel-assessment.png` — risk level, detected signals, recorded evidence, and recommended action.
5. `alert-task.png` — the resulting farm alert and follow-up task.
6. `ai-explanation.png` — optional explanation, visibly separate from the Farm Sentinel assessment.

For desktop captures, use a consistent browser size around 1440 × 1000. Also verify the same screens at a phone width before capture. Save only genuine screenshots under this directory, then embed them in the README with relative paths.
